# Tugboat landing page

Open [index.html](index.html) in a browser. The page, workspace tour and FAQ work without a build, JavaScript, or an internet connection. The FAQ explains the choice of Brig and links to the Brig and Docker Sandboxes documentation. External links need internet access.

With JavaScript enabled, the hero diagram plays when it comes into view. The shared project tile turns green when either agent's request reaches it. Codex and Claude Code then each send a signal from their box's shadow toward other Mac folders. The Codex signal stops at the left boundary. The Claude Code signal stops at the right boundary. Each contact point turns red when its signal arrives. Each color stays at full strength for 0.9 seconds before fading. The diagram pauses for three seconds after the final fade, then repeats automatically. With reduced motion enabled, the diagram shows the result without movement.

To preview the page over HTTP, run this command from the repository root:

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory landing
```

Open [the local preview](http://127.0.0.1:8000/).

The page uses `#005e9d` as its main color. The tour images show the Tugboat interface with sample project data. Their embedded metadata records their source. Check product and sandbox claims against the [user guide](../docs/user-guide.html).
