Tugboat handbook

Use Codex and Claude Code on a local project. Follow a chat into its guest environment, or find the source and tests for a change to Tugboat.

  • User guide

    Set up your first chat, switch agents, review changes and recover from a problem. For an existing issue, start with troubleshooting by symptom.

  • Application architecture

    Follow a chat from the Mac into a Brig guest. Trace the terminal, provider account, project files and usage records on the runtime map.

  • Developer guide

    Find the module that owns a behavior. Use its maintenance instructions, failure cases and tests. Follow two worked feature changes.

  • Architecture decisions

    Read the decisions behind isolation, session identity, provider accounts, storage and delivery. Each decision includes its consequence and links to the implementation.

  • Agent guide

    Read this before working on the repository. It explains how to scope a change, preserve boundaries, verify results and follow the repository instructions.
